# Code Quality Principles

## Documentation Standards

**Critical Rule**: Avoid documentation bloating at all costs.

### What This Means

- Keep documentation concise and focused
- Only document what is necessary for understanding and usage
- Avoid redundant explanations
- Don't create documentation just for the sake of having documentation
- Every line of documentation should provide value
- Remove or consolidate duplicated information

### Apply To

- README files
- Code comments
- API documentation
- Agent definitions
- Usage guides
- Inline documentation

### Exception

Only create comprehensive documentation when explicitly requested by the user or when it's critical for understanding complex systems.
